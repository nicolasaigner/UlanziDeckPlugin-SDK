⚙️ Configurações do Plugin

Configure suas credenciais do SmartThings. Estas configurações são salvas em arquivo e compartilhadas por todas as ações do plugin.

Device ID *
ID do seu dispositivo Samsung no SmartThings
Personal Access Token (PAT) *
Token de acesso pessoal do SmartThings
ℹ️ Como obter as credenciais:

Device ID:
1. Acesse my.smartthings.com
2. Selecione seu dispositivo
3. Copie o ID da URL

Token (PAT):
1. Acesse account.smartthings.com/tokens
2. Clique em "Generate new token"
3. Marque: devices:read, devices:write, devices:execute
4. Copie o token gerado
